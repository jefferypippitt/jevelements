## Findings considered and rejected

- **Overlay XSS**: no `innerHTML` anywhere in the extension. Page text is set via `textContent`, and markdown links are limited to http(s).
- **Backend path traversal**: `filePath` (`store.ts:26-31`) allows only a UUID, one of four folders and a strict name regex. `isProjectMeta` validates every name field.
- **Committed secrets**: `backend/.env` is gitignored and untracked; `.env.example` holds empty placeholders only.
- **Duplicate chunk uploads after `askExtension` resends**: the backend's offset check (`store.ts:42-43`) returns 409 for a repeated chunk, and offset-0 writes are idempotent.
- **Most `next@16.3.6` advisories** (image optimization SSRF, ISR/SSG cache poisoning, metadata image routes): this app uses none of those features. The version bump in 006 covers them anyway.
- **Four identical tracked copies of the `typesafe-ai` skill**: real but trivial housekeeping, not worth a plan.
- **The `cn` npm package in `backend/package.json`** (run 2): it's shadcn's official package (`github.com/shadcn-ui/cn`), not a typosquat.
- **Making `JEV_API_TOKEN` mandatory, constant-time token comparison, and token storage in `chrome.storage.local`** (run 2): dropped at the user's direction, because the project doesn't use the token. 007 and 012 were revised accordingly.
- **Caching the TypeSafe client per process** (run 2): negligible benefit.
- **Never-disconnected ResizeObserver at `inspector.ts:958`** (run 2): it only observes a detached frame after the drawer closes.
- **Status-page `<a href={run.url}>`** (run 2): dev-only, and React 19 already neutralizes `javascript:` URLs.
- **Prompt-injection text in `backend/src/lib/scaffold.ts`**: that is the standard Next.js AGENTS.md block written into generated apps, not content aimed at an auditor.

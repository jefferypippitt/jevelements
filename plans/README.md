## Findings not yet planned (from the same audit; ask for a plan if wanted)

- **Cancel a running capture.** ✕/Esc only hide the drawer; the capture keeps clicking and uploading for minutes. Needs an `AbortController` threaded through `interactions.ts`, `states.ts`, `sweep.ts` and `scroll.ts`. M effort, MED risk. Natural follow-up to 005.
- **Service worker fetches page-chosen URLs with `credentials: 'include'`** (`background/index.ts:142-166`). The probe reply channel can be forged by the page (`content/runtime.ts:25-41`), and `extensionFor` accepts any non-HTML body when a `?url=` parameter names a media file. M effort.
- **Small correctness batch**: the scheme check scrolls without `behavior: 'instant'` (`scheme.ts:293,341`); `jev:capturing` replies with a boolean, which `askExtension` treats as no reply, so it resends and reports an error (`reply.ts:10`, `background/index.ts:103-108`); three diverged data-URL→Blob helpers (`media.ts:68`, `sweep.ts:349`, `inspector.ts:41`).
- **Extension↔backend contract test**: folder names, size limit, `/capture/` paths and component naming are kept in sync by hand across `backend/src/lib/{store,archive,judgment}.ts` and `frontend/jevelements/src/shared/{files,kit,prompt}.ts`.
- **Full-section screenshot taken after the sweeps** (`inspector.ts:595-629`), so it can show a state left behind by clicks.
- **Stylesheet filtering is O(rules × subtree)** (`extract.ts:384-390,1583-1624`). It can freeze the page when `<body>` is picked on a large site. Medium confidence; not timed.
- **The write guard covers only the top frame's page context** (`probe/writes.ts`). A `declarativeNetRequest` session rule would also cover iframes, workers and the late-injected probe.
- **Split `sweep.ts`** (2.3K lines). Pull the pure fit/easing/pixel math into testable modules first.
- **Direction options**: per-site opt-in probe instead of always-on `<all_urls>` page-context patches; an options page for `backendUrl`/`backendToken`; a headless golden-capture harness over `test/*.html`.

## Findings considered and rejected

- **Overlay XSS**: no `innerHTML` anywhere in the extension. Page text is set via `textContent`, and markdown links are limited to http(s).
- **Backend path traversal**: `filePath` (`store.ts:26-31`) allows only a UUID, one of four folders and a strict name regex. `isProjectMeta` validates every name field.
- **Committed secrets**: `backend/.env` is gitignored and untracked; `.env.example` holds empty placeholders only.
- **Duplicate chunk uploads after `askExtension` resends**: the backend's offset check (`store.ts:42-43`) returns 409 for a repeated chunk, and offset-0 writes are idempotent.
- **Most `next@16.3.6` advisories** (image optimization SSRF, ISR/SSG cache poisoning, metadata image routes): this app uses none of those features. The version bump in 006 covers them anyway.
- **Four identical tracked copies of the `typesafe-ai` skill**: real but trivial housekeeping, not worth a plan.
- **Prompt-injection text in `backend/src/lib/scaffold.ts`**: that is the standard Next.js AGENTS.md block written into generated apps, not content aimed at an auditor.
